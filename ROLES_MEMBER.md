# Role Definition: Member

The **Member** role is the standard "Doer" level. This role is optimized for engineers, designers, and product managers who focus on executing tasks and moving projects forward.

## 🚀 Core Permissions
* **Issue Lifecycle:** Create, edit, and delete their own issues.
* **Kanban Interaction:** Move issues between columns (e.g., moving a task from "Todo" to "In Progress").
* **Collaboration:** Comment on any issue and mention other team members.
* **Project Visibility:** Access and search all active projects within the organization.

## 🖥️ Primary UI Elements
* **The "Create" Interface:** Full access to the "New Issue" modal and keyboard shortcuts (e.g., `C`).
* **Personal Dashboard:** A filtered view showing "Issues Assigned to Me."
* **Activity Feed:** Real-time updates on projects they are actively participating in.

## 🚫 Restrictions
* Cannot create or delete Projects.
* Cannot invite or remove other users.
* Cannot access any Workspace or Project settings.
